# NUSAdvisor+

A conversational AI academic advisor for NUS students — live at **https://d2k55gvobdiojf.cloudfront.net**

Ask about courses in plain English. The agent searches 7,100+ NUS modules semantically, filters by faculty and level, tracks your completed and planned courses, and holds multi-turn conversations so you can refine your search naturally.

## Features

- **Semantic course search** — searches 7,100+ NUS modules by meaning
- **Faculty and level filtering** — mention "SoC", "business school", or "undergraduate" and the agent filters automatically
- **Course state tracking** — tell the agent which courses you've taken or planned; it won't re-recommend them and uses them for prerequisite reasoning
- **Multi-turn memory** — follow-up questions work naturally without repeating context
- **Streaming responses** — answers appear token-by-token as the model generates them
- **Persistent sessions** — conversations survive page refreshes; pick up where you left off
- **Multi-session sidebar** — manage multiple chats; titles auto-generated by the LLM

## Stack

| Component | Choice |
|-----------|--------|
| LLM | Gemini (`gemini-3.1-flash-lite-preview`) |
| Agent orchestration | LangGraph |
| Vector DB | ChromaDB (persistent, cosine similarity, on EBS) |
| Embeddings | `all-MiniLM-L6-v2` (384-dim) |
| Session persistence | LangGraph AsyncSqliteSaver + aiosqlite |
| Backend | FastAPI + uvicorn (async, streaming SSE) |
| Frontend | React + Vite |
| Deployment | AWS EC2 t3.micro + EBS 20GB + S3 + CloudFront |
| Containerisation | Docker |
| Course data | NUSMods v2 API (public) |
| Evaluation | Arize Phoenix + custom evaluators |

## Setup

```bash
git clone <repo-url>
cd NUSAdvisor

python3 -m venv venv
source venv/bin/activate

pip install -r backend/requirements.txt
```

Create `backend/.env`:
```
GEMINI_API_KEY=your_key_here
GEMINI_MODEL=gemini-3.1-flash-lite-preview
CHROMA_PERSIST_DIR=../data/chromadb
CHECKPOINT_DB_PATH=../data/checkpoints.db
```

### Ingest NUS modules (first time only)

```bash
cd backend
python ingest.py
```

Fetches all NUS modules from the NUSMods API, embeds them, and stores them in ChromaDB (~15 minutes on first run).

## Evaluation

The agent was built using an evaluation-driven development approach — evals were built before iterating on the agent, so every prompt change and tool addition was measured.

### Framework

- **28-question test dataset** covering realistic student queries: department filtering, level filtering, course state tracking, multi-turn conversations, and prerequisite reasoning
- **4 code-based evaluators and 1 LLM-as-judge evaluator**, tracked via Arize Phoenix

### Evaluators

| Evaluator | Type | What it checks |
|-----------|------|----------------|
| `tool_calling_eval` | Code | Compares expected vs actual tool call list |
| `call_efficiency_eval` | Code | Checks for redundant `search_modules_tool` calls |
| `course_exists_eval` | Hybrid | Uses LLM to extract course codes from the response, then verifies each against ChromaDB |
| `search_relevance_eval` | LLM-as-judge | Calls Gemini with a relevance prompt to assess response quality |
| `courses_state_eval` | Code | Compares expected vs actual taken/planned course lists |

### Results (28 questions)

| Evaluator | Score |
|-----------|-------|
| `tool_calling_eval` | 89.3% |
| `call_efficiency_eval` | 92.9% |
| `course_exists_eval` | 95.9% |
| `search_relevance_eval` | 96.4% |
| `courses_state_eval` | 100% |

### What the evals caught

| Failure | Evaluator | Fix |
|---------|-----------|-----|
| Agent paraphrasing course codes (e.g. `CS3244` → `CS3244A`) | `course_exists_eval` | System prompt: copy course codes verbatim from tool output |
| Agent using `search_modules_tool` for direct code lookups | `call_efficiency_eval` | System prompt: use `get_module_by_code` when a specific code is mentioned |
| Agent calling `search_modules_tool` before recording a course to state | `call_efficiency_eval` | System prompt: record course immediately, no search needed |
